📖 大學章句序 한자 스와이프 챌린지
大學章句序의 주요 漢子와 訓音을 게임처럼 재미있게 익힐 수 있는 인터랙티브 학습 플랫폼입니다.

🎮 게임 방법
시작: 화면 중앙에 나타난 漢子와 아래의 訓音을 확인합니다.

스와이프(Swipe) 액션:

오른쪽으로 밀기: 제시된 訓音이 정답이라고 판단될 때

왼쪽으로 밀기: 제시된 訓音이 오답이라고 판단될 때

레벨업: 10문제를 연속으로 맞히면 다음 단계로 진입하며, 시간이 점점 촉박해집니다.

주의: 오답을 선택하거나 제한 시간이 초과되면 게임이 종료되며 처음부터 다시 도전해야 합니다.

🛠 기술 스택
Language: HTML5, CSS3, JavaScript

Platform: GitHub Pages (Web-based)

Design: Responsive Mobile-first Design
